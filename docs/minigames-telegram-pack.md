# Пак MogobeGames.zip

Пак передан пользователем 18 октября 2026 года. Проверены 21 SWF, целостность ZIP и SHA-256 сохранённых файлов. Размер ZIP — 20 132 659 байт, суммарный размер SWF — 20 136 110 байт. Все 21 оригинала сохранены без изменения байтов; источник и контрольные суммы находятся в `assets/original/sources.json` и `assets/original/telegram-games-import.json`. Сам архив и файлы из Downloads для дальнейшей работы не нужны.

Файлы импортированы для дальнейшего подключения. Новые команды, выплаты и игровые входы в этом изменении не добавлялись; подключённой миниигрой остаётся GoldFishing.

## Основная находка — MatchIt2

Ранее для MatchIt был известен только AS3-загрузчик `MatchIt.swf`, который запрашивает `/Swf/Apps/Games/MatchIt2.swf`. В новом паке найдено тело по этому имени: графика, 14 звуковых ресурсов, 184 спрайта и AS2-скрипты игры. Это головоломка на соединение одинаковых плиток. Игра содержит собственные инструкцию, игровое поле, таймер, очки и завершение. Русский интерфейс этой версии не подтверждён: проверенная инструкция английская.

Оригинальный загрузчик дополнительно сохранён из прежнего пользовательского архива как `assets/original/Swf/Games/MatchIt.swf`. Он получает счёт и завершение через `LocalConnection` (`SendToGame`, `receivedFromGame`, `sendScore`, `onGetScore`, `gameOver`), затем отправляет `GAME_EVENT`. В теле действительно есть `_root.setScore(...)` и `_root.gameOver()`. Наличие этих вызовов не доказывает корректность передачи итогового счёта в Ruffle: это нужно отдельно проверять при подключении.

В отдельном headless Edge с закреплённым Ruffle, без звука, подтверждены показ оригинальной инструкции и переход по Start на игровое поле. Кадры: `verification/telegram-games/MatchIt2-menu.png` и `MatchIt2-action-1.png`. Полное прохождение, работа LocalConnection через загрузчик и серверная выдача наград пока не проверены. В коде есть обращения к старым Mochi-сервисам рекламы, магазина и рекордов; в проверке эти внешние домены заблокированы, игровое поле всё равно запускается. Для будущего подключения нужны адаптер AS2/AS3, проверка счёта и серверная политика наград.

## Что этот пак не восстановил

- Нет отдельного файла или символа `GoldFishing_mlGameHelp`: отсутствующие иллюстрации справки рыбалки пока не найдены.
- Нет XML Bowling/Hoops/Darts и дополнительных ресурсов BeautySalon/Bling. Новая копия BeautySalon всё ещё загружает `/Swf/Assets/Games/BeautySalon/BeautyItems.swf` и ожидает данные `beautySalon__getCategories` / `beautySalon__getWCateItems`.
- Hockey остаётся загрузчиком: отдельного `HockeyAS1.swf` здесь нет.
- Наличие файлов не подтверждает русскую локализацию и готовность всех игр к многопользовательскому режиму.

## Расположение файлов

Основные файлы находятся в `assets/original/Swf/Games/`. Тело MatchIt2 сохранено по ожидаемому загрузчиком пути `assets/original/Swf/Apps/Games/MatchIt2.swf`. Вариант GoldFishing из пака сохранён как `assets/original/Swf/Games/Preserved/GoldFishing-Telegram.swf`; текущая русская GoldFishing не заменялась. Дополнительные материалы анализа и декомпиляции находятся в игнорируемой папке `verification/telegram-games/`.
