# Чат-команды

[На главную](../README.md) · [Клиент](../client/README.md) · [Сервер](../server/README.md)

Введите команду в игровой чат и нажмите Enter или кнопку отправки. Аргументы в квадратных скобках необязательны; сами скобки вводить не нужно. Справка внутри игры — `/help`: она показывает команды с учётом текущих прав.

## Команды для всех игроков

| Команда | Действие | Пример |
| --- | --- | --- |
| `/help` | Открывает панель доступных команд | `/help` |
| `/room локация` | Переносит в указанную локацию | `/room Novograd` |
| `/shop ключ` | Открывает доступный магазин по его ключу | `/shop clothesstore` |
| `/online` | Показывает общее число игроков в мире; ответ видит только отправитель | `/online` |
| `/exit` | Возвращает к выбору могоби с сохранением авторизации | `/exit` |

### Переходы между локациями

`/room` принимает ключ комнаты, имя её SWF без расширения или русское название. Регистр не важен; названия из нескольких слов вводятся целиком, без кавычек.

```text
/room novograd
/room InfoBoard
/room Солнечная улица
/room Вьюгово
```

Полный список ключей, имён и названий — в [каталоге локаций](../server/src/world/rooms.json). Обычный вход и вход после `/exit` начинают игру в Новограде.

### Открытие магазинов

`/shop` открывает указанный магазин из любой локации без необходимости подходить к торговой точке. При обычном посещении персонаж должен дойти до исходной точки магазина. Доступ проверяется в обоих случаях: магазин должен быть открыт, а для магазина с ограничением администраторам нужны соответствующие права.

Стартовые магазины:

| Магазин | Команда |
| --- | --- |
| Могоцентр | `/shop mall` |
| Лига | `/shop sportstore` |
| Стиляги | `/shop clothesstore` |
| МогоДом | `/shop furniturestore` |
| Солнечная улица | `/shop kingsroad` |
| Солнцеморье | `/shop sunandsea` |
| Спа | `/shop spa` |
| Сказкино | `/shop skazkino` |
| Дом рукоделия | `/shop jewelrystore` |
| Полое дерево | `/shop foresttree` |
| Вьюгово | `/shop vugovo` |
| Бумаги | `/shop bumagsstore` |
| Еда и игрушки для бумаг | `/shop bumagsfoodtoysstore` |
| Зелья для бумаг | `/shop bumagspotionstore` |

Магазины, их доступность и ассортимент редактируются через отдельную админку. Для своего магазина используется назначенный ему ключ: например, `/shop style` работает после создания магазина `style`. Исторический ассортимент восстановлен приблизительно; стартовые цены и опыт обычных магазинов — по 10.

Закрытые административные каталоги:

| Команда | Содержимое |
| --- | --- |
| `/shop admin1` | Одежда и украшения, с примеркой на персонаже |
| `/shop admin2` | Бумаги, корм, игрушки и зелья |
| `/shop admin3` | Интерьер дома, транспорт и пазлы |

Каждый магазин открывается отдельной командой. Например, для одежды отправьте `/shop admin1`. Новые предложения административных каталогов по умолчанию бесплатны и не дают опыт; настройки существующих предложений сохраняются.

## Команды администратора

| Команда | Действие | Пример |
| --- | --- | --- |
| `/give item ID [ник]` | Выдаёт вещь из каталога в инвентарь | `/give item 100 Player_2` |
| `/give exp число [ник]` | Начисляет опыт | `/give exp 500 Player_2` |
| `/give coins число [ник]` | Добавляет монеты к текущему балансу | `/give coins 100 Player_2` |
| `/alert текст` | Показывает объявление всем игрокам во всех локациях, включая отправителя | `/alert Через пять минут перезапуск сервера` |

### Выдача вещей, опыта и монет

Без ника `/give` выдаёт указанное самому отправителю. С ником — существующему могоби, в том числе находящемуся вне сети. Регистр ника не важен.

```text
/give item 100
/give exp 500
/give coins 1000
/give item 101 Player_2
/give exp 1500 Player_2
/give coins 250 Player_2
```

- `item`: ID от 1 до 1 000 000. Предмет должен существовать в каталоге админки; продавать его в магазине необязательно. Повторная выдача уже имеющейся вещи отклоняется. Выдача не списывает монеты и не начисляет опыт. Надевание зависит от типа вещи и наличия подходящей анимации.
- `exp`: целое число от 1 до 1 000 000 за команду. Подключённый получатель видит оригинальную анимацию начисления опыта.
- `coins`: целое число от 1 до 1 000 000 000. Указанная сумма добавляется к балансу; итоговый баланс не может превышать 1 000 000 000.

Ник получателя указывается одним аргументом, без пробелов. Разрешены буквы латиницы и кириллицы, цифры и `_`; длина — 4–15 символов. Отрицательные значения и дробные числа не принимаются.

### Объявления

В `/alert` нужен непустой текст длиной до 230 символов. Сообщение показывается в оригинальном окне всем находящимся в мире игрокам независимо от комнаты. Если уже открыты справка или другое сообщение, объявление ждёт закрытия этого окна.

Права администратора выдаются в отдельной админке или серверной CLI; чат-команды для назначения прав нет. Порядок настройки — в [README](../README.md#права-администратора-и-админка).

## Быстрое переподключение

**F5** в мире переподключает в текущую локацию. Это клавиша клиента, её не нужно вводить в чат. Координаты персонажа в базе не сохраняются; после обычного выхода и нового входа стартовой локацией остаётся Новоград.
