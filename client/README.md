# Windows-клиент

[Назад к проекту](../README.md)

Go-оболочка Wails запускает оригинальные SWF через встроенный Ruffle в WebView2. Сервер FastAPI работает отдельно. Flash Player и браузерный плагин Adobe не требуются.

## Сборка и запуск

На Windows нужны Go 1.25+, Python 3.12+ и WebView2 Runtime. Из корня репозитория:

```powershell
python tools\build_client.py
.\StartClient.bat
```

Скрипт подготавливает ресурсы из `assets/`, собирает EXE и создаёт `dist/Mogobe/`. Wails закреплён в `go.mod`; Node.js, Java и JPEXS для обычной сборки не нужны. Готовый клиент требует только WebView2 Runtime. Основные оригиналы, адаптер и Ruffle встроены в EXE. Графика предметов загружается по мере использования с выбранного сервера через локальный шлюз; внешний архив не требуется.

Если старый EXE открыт и Windows запрещает замену, новая сборка сохраняется как `Mogobe-update.exe` рядом с ним. Настройки подключения при сборке не сбрасываются.

## Подключение

Рядом с EXE лежит `client.json`:

```json
{
  "server_url": "http://localhost:8000",
  "request_timeout_seconds": 15
}
```

```powershell
.\Mogobe.exe --server https://mogobe.example.com
.\Mogobe.exe --config C:\Mogobe\client.local.json
```

Приоритет: `--server` → файл `--config` или `client.json` рядом с EXE → localhost. Поддерживаются HTTPS и адреса с префиксом пути. Шаблон удалённого подключения — `client.remote.example.json`. Из корня можно использовать `StartRemoteClient.bat https://mogobe.example.com`; без аргумента он читает `MOGOBE_SERVER_URL`.

Для каждого сервера и одновременно открытого окна используется отдельный профиль WebView2. Игровой TCP-поток SWF проходит через локальный WebSocket Go-шлюза на `/legacy/socket` сервера. Дополнительный открытый порт 9339 на сервере не нужен.

## Управление и авторизация

Полный список игровых команд и примеры — в [справочнике чат-команд](../docs/chat-commands.md).

| Действие | Результат |
| --- | --- |
| Клик по земле | Оригинальные поиск пути и анимация ходьбы |
| Карта или проход | Переход в доступную комнату |
| `/exit` | Возврат к выбору могоби с сохранением авторизации |
| `/shop <key>` | Оригинальное окно магазина; отдельные магазины доступны только администраторам |
| `/help` | Панель доступных команд с учётом текущих прав |
| `/alert текст` | Объявление всем игрокам во всех локациях (администратор) |
| `/online` | Число игроков, видимое только отправителю |
| `/room Novograd` | Просмотр комнаты по имени SWF или русскому названию |
| F5 в мире | Переподключение в текущую комнату |

Обычный вход начинается в Новограде. Появление случайное; после прохода — возле входа в новую комнату. Оригинальная заставка остаётся до загрузки комнаты, панели и персонажа.

«Запомнить имя» добавляет могоби в оригинальный список, «Запомнить пароль» сохраняет сессию без хранения пароля. В списке до шести могоби, по четыре на странице. Кнопка «Выйти» на экране выбора удаляет выбранную запись и отзывает её сохранённую сессию при доступном сервере.

Данные находятся в `%LOCALAPPDATA%\Mogobe\accounts-<server-hash>.dat`; дополнительные окна получают отдельные файлы. Токены зашифрованы Windows DPAPI для текущего пользователя и не передаются в JavaScript или Flash. Недоступность сервера не очищает список.

## Разработка

| Путь | Назначение |
| --- | --- |
| `main.go`, `profiles_windows.go` | Окно, ресурсы и изолированные профили |
| `internal/config/` | Загрузка и проверка подключения |
| `internal/accounts/` | Список могоби и DPAPI |
| `internal/gateway/` | REST, старые запросы SWF и игровой WebSocket |
| `frontend/*.js`, `*.css`, `index.html` | Код запуска и адаптации интерфейса |
| `../tools/host/MogobeHost.as` | Загрузка оригиналов и исправления их поведения |

Копии ресурсов и страницы регистрации в `frontend/` генерируются. Правьте оригинальные страницы в `assets/original/registration-pages/`, поведение — в нашем JS или SWF-адаптере.

Из этой папки на Windows: `go test ./...`. Нативные проверки окна и пересборка адаптера описаны в [инструментах](../tools/README.md).

Админка запускается отдельно через `StartAdmin.bat`; в игровой клиент она не встроена. Права проверяет сервер. Изменения открытого магазина доставляются игровыми событиями без перезапуска и фонового опроса каталога. Цена повторно проверяется при покупке; если она изменилась, требуется заново выбрать товар. Купленные вещи сохраняются в инвентаре, за покупку начисляется настроенный сервером опыт с оригинальным попапом. Подсказка профиля показывает «Уровень: N». Администратор может выдать себе или другому могоби вещь, опыт и монеты командами `/give item ID [ник]`, `/give exp ЧИСЛО [ник]` и `/give coins ЧИСЛО [ник]`; его золотой значок могокарты обновляется при изменении прав. Расстановка мебели пока не реализована.

Одежда надевается щелчком по вещи в оригинальном инвентаре профиля. Щелчок по надетой вещи на большом могоби снимает её. Изменения сразу видят игроки в комнате; одежда сохраняется при переходах, F5 и повторном входе. Кнопка фотоаппарата копирует портрет с одеждой в буфер обмена Windows — его можно вставить в графический редактор или мессенджер. Изображение обрабатывается локально, без загрузки на игровой сервер.

В командах `/give` ник необязателен: без него вещь, опыт или монеты выдаются себе, с ним — указанному могоби. Получатель может находиться вне сети. `/help` использует оригинальную рамку и шрифт; `/alert` показывает сообщение каждому подключённому игроку.

Адаптер использует штатное завершение ходьбы и точный контур исходного триггера для открытия назначенного сервером магазина; клики по произвольным областям не перехватываются. Привязки загружаются при входе в комнату и обновляются событиями редактирования. Графика предметов кэшируется Go-шлюзом в памяти: до 32 МиБ/256 файлов на выбранный сервер, срок 30 минут; одинаковые одновременные запросы объединяются. Ошибки и каталоги с ценами не кэшируются. Успешная покупка обновляет каталог одним серверным событием. Предпросмотр бумаг и интерьера вписывается в 120×140 без увеличения исходной графики.

При покупке и изменении цены/остатка обновляются данные существующего каталога и текущие ячейки, без сброса категории и номера страницы. Выбранная вещь сохраняется. Полное изменение состава каталога обрабатывается отдельно.

Адаптер обрабатывает штатное завершение ходьбы и точный контур точки до создания старого окна. Каталог запрашивается перед показом магазина; пустое промежуточное окно не открывается.
