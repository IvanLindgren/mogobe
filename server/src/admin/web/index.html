Настройки магазина

Точку можно назначить другому магазину. Для нескольких точек используйте Ctrl. Изменения действуют без перезапуска.

Категории

При назначенном слоте перенос товара в эту категорию меняет его слот у всех владельцев. Пустое поле сохраняет индивидуальную разметку вещей.

Описание предмета

Разметка восстановлена по графике, исходный серверный каталог не найден. Слоты: 3 — головной убор, 7 — причёска, 4 — верх, 1 — низ, 11 — обувь, 18/19 — очки/лицо, 2/9/10/12/23 — аксессуары. Слот 0 и категория «Неполные анимации» — вещь пока нельзя надеть. Предметы бумаг, транспорт и интерьер не являются одеждой; их игровые механики ещё не подключены.
